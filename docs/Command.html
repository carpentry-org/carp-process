Command

T

module

Module

a command to be run: the executable path, its args (not including argv[0]), and the string to pipe to its standard input.

Build one with new and arg rather than by hand.

arg

defn

(Fn [Command.T, (Ref String a)] Command.T) 

                        (arg c a)

appends the argument a to the command c.

Arguments are passed to execvp(3) as-is, never through a shell, so they need no quoting and cannot be split or interpreted.

new

defn

(Fn [(Ref String a)] Command.T) 

                        (new path)

creates a command that will execute path, with no arguments and no piped standard input.

path is resolved through PATH by execvp(3).

set-stdin

defn

(Fn [Command.T, (Ref String a)] Command.T) 

                        (set-stdin c s)

sets the string s to be piped to the command’s standard input.

Setting a non-empty string is what makes Process.run open a stdin pipe at all; the empty string (the default) leaves the child’s stdin inherited from the parent.
