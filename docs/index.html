carp-process

Subprocess management for Carp.

Spawns and manages child processes with POSIX semantics: fork/execvp, pipe setup, descriptor hygiene and signal-aware waiting. Arguments go to execvp(3) directly, never through a shell, so there is nothing to quote and nothing to inject.

Everything here is synchronous and reads whole streams into memory.

Quick start

(load "git@github.com:carpentry-org/carp-process@master")

(let [out (Process.run-combined
            &(=> (Command.new "echo") (Command.arg "hello")))]
  (println* (Process.Output.stdout &out)))

Deadlocks

Process.run drains stdout and then stderr, one after the other. A child that fills the stderr pipe buffer while run is still reading stdout will block, and so will run. Use run-combined, which merges the two streams at the OS level and has only one buffer to drain.
